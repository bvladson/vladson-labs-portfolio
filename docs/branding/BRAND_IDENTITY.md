## O que Vladson Labs é — e o que não é

**É** uma iniciativa tecnológica autoral que organiza, sob uma identidade própria, sistemas
projetados, construídos e operados pelo criador para resolver problemas empresariais reais.

**Não é** uma empresa formalmente constituída, uma marca registrada nem um fornecedor
comercial estabelecido. Nada neste repositório deve afirmar o contrário.

## As três camadas de identidade

A regra que governa cada decisão de nome neste ecossistema:

| Camada | O que é | Exemplo |
| --- | --- | --- |
| **1 — Institucional** | A iniciativa que organiza os projetos | Vladson Labs |
| **2 — Produto** | O software, com identidade própria | Elofarol CRM |
| **3 — Empresa atendida** | Quem usa o software na operação | MAG Móveis Corporativos |

**O produto não é o cliente.** A identidade do software nunca substitui a identidade
comercial da empresa que o utiliza. No site institucional da MAG, o nome MAG permanece. Nos
dados, catálogos, domínios, contratos, integrações e registros históricos, os nomes das
empresas atendidas permanecem.

## Limites de autoria

| Produto | Participação |
| --- | --- |
| Alvorumo BI v1 e v2, Elofarol CRM Web e Mobile, Docalume DMS, Vitracora CMS | Desenvolvimento original |
| Sabelar AI | Arquitetura, integração e isolamento. Os modelos e o motor de inferência são de terceiros |
| Pautelo PM | Customização e localização sobre o Leantime (AGPL-3.0), de terceiros |
| Entreliga iPaaS, Operalvo Core | Integração e extensões sobre ERPNext, Frappe e n8n, de terceiros |
| Fortearco Infra | Arquitetura, documentação e operação. Os componentes são de terceiros |

A identidade Vladson Labs não é usada para reivindicar propriedade intelectual de terceiros
nem das organizações atendidas. Ver `PRODUCT_REGISTRY.json` para as licenças por projeto e as
pendências registradas.
